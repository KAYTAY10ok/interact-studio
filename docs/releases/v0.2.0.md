## Interact Studio 0.2.0

Cette version améliore l’édition quotidienne d’un projet en ajoutant l’enregistrement automatique, la récupération des brouillons, les suggestions sémantiques, les commandes Git et un catalogue d’extensions.

- **Auto-save et récupération** — réglez le délai d’enregistrement dans les préférences. Récupérez un brouillon local après une interruption, y compris pour un onglet sans nom.
- **Suggestions locales et LSP** — conservez les extraits et les mots du document. Installez `clangd` pour C/C++ ou `rust-analyzer` pour Rust afin d’enrichir les suggestions et les diagnostics. Les serveurs locaux démarrent à la demande.
- **Formatage et tests** — lancez le formateur du langage sur le document actif et exécutez la commande de test choisie dans la console du projet.
- **Git et GitHub** — configurez l’identité Git du dépôt, gérez vos branches et utilisez fetch, pull ou push depuis Studio. La connexion GitHub s’appuie sur GitHub CLI.
- **Personnalisation** — les réglages sont accessibles depuis les préférences et un fichier JSON. Le catalogue propose 30 extensions installables, avec des thèmes, des extraits et des commandes à lancer à la demande.

### Téléchargements

| Système | Fichiers |
| --- | --- |
| Windows 10/11 x64 | `InteractStudio-v0.2.0-windows-x86_64-setup.exe` ou `InteractStudio-v0.2.0-windows-x86_64.zip` |
| Debian 12 amd64 | `interact-studio_0.2.0_amd64.deb` ou `interact-studio-v0.2.0-linux-x86_64.tar.gz` |

L’installateur Windows est fourni sans signature Authenticode. Comparez la somme SHA-256 du fichier téléchargé à celle de `SHA256SUMS.txt`.
