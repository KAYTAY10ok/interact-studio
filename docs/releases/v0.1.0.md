## Interact Studio 0.1.0

Première version publique de l’IDE natif en C++ et Qt. Elle comprend l’édition par onglets, la recherche, la vue scindée, la compilation C++ et Rust, la navigation vers les définitions, le contrôle de version Git et les extensions de commande JSON. Les panneaux, thèmes et raccourcis sont personnalisables.

### Téléchargements

- **Windows 10/11 x64** — installeur `InteractStudio-v0.1.0-windows-x86_64-setup.exe` ou ZIP portable. Les shells interactifs s’ouvrent dans une console Windows séparée. Les tâches affichent leurs sorties dans Studio.
- **Debian 12 amd64** — paquet `interact-studio_0.1.0_amd64.deb` ou archive `.tar.gz`. Le terminal interactif est intégré à la fenêtre.
- **Vérification** — comparez le SHA-256 du fichier téléchargé à l’entrée correspondante dans `SHA256SUMS.txt`.

L’intégration Git nécessite Git, et les connexions Docker, SSH, WSL ou GitHub utilisent les outils installés sur votre machine. Les compilateurs et serveurs de langage sont facultatifs.
